# alphaai-sample (AlphaAI seed dataset)

A small instruction/response corpus written for AlphaAI, used to verify the
training foundation end to end. It is **not** a pretraining dataset and it
contains no text from other models.

| Field | Value |
| --- | --- |
| Name | `alphaai-sample` |
| Version | 1.0.0 |
| License | Apache-2.0 |
| Source | written for AlphaAI |
| Created by | AlphaAI |

## Layout

```
dataset.json     declared metadata (name, version, license, source, schema)
train.jsonl      training split  (one {"instruction","response"} object per line)
valid.jsonl      validation split
manifest.json    generated: record counts, byte sizes, SHA-256 per split
```

## Commands

```shell
alphaai train status      # is the dataset present and valid?
alphaai train validate    # recompute hashes, report every problem
alphaai train prepare     # dedupe + deterministic re-split + rewrite manifest
alphaai train tokenize    # train the AlphaAI byte-level BPE tokenizer on it
alphaai train finetune    # reference training run (needs the torch extra)
alphaai train evaluate    # dataset/tokenizer/live-engine/checkpoint metrics
```

## Adding your own dataset

Create `datasets/<name>/dataset.json` with at least `name`, `version`, `license`
and `source`, put one JSON object per line in `train.jsonl` / `valid.jsonl`, then
run `alphaai train prepare` to generate the manifest. Formats supported:
`.jsonl`, `.json`, `.csv`, `.tsv`, `.txt`.

Keep the license honest: if your corpus includes text generated by another model,
say so in `source` and in `license`, because the licenses of that model's outputs
apply to the derived weights.
