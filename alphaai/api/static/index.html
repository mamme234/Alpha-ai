Image Generation
Not available in this deployment.

        

          
◆This is a real state, not an error in the page. The AlphaAI deployment you are using serves text generation from an installed local model (llama.cpp + a GGUF instruct model). No image model, diffusion runtime or image service is installed, and AlphaAI does not call external AI APIs — so nothing is generated and nothing is faked here.

          
To make this view real you would install an image runtime on the inference host and expose it as a new AlphaAI capability. Until then, this workspace stays empty on purpose, and the API reports no image engine.
